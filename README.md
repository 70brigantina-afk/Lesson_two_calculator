# Семейный бюджет

Веб-приложение для учёта семейных финансов: доходы, расходы, долги и накопления. Работает полностью в браузере, без сервера и регистрации.

## Возможности

- Учёт операций по месяцам с остатком на начало периода
- Плановый лимит расходов с индикатором перерасхода
- Статистика по категориям и банковским счетам
- Финансовые подсказки на основе ваших данных
- Поиск, фильтрация и сортировка истории
- Экспорт в CSV (Excel) и JSON (резервная копия)
- Адаптивная вёрстка для телефона и планшета

## Быстрый старт

### Вариант 1 — открыть в браузере

1. Скачайте или клонируйте репозиторий.
2. Откройте `index.html` двойным щелчком — появится лендинг.
3. Нажмите **«Открыть калькулятор»** или перейдите в `app/index.html`.

### Вариант 2 — локальный сервер (рекомендуется)

```bash
# Python 3
python -m http.server 8080

# или Node.js (npx)
npx serve .
```

Затем откройте: [http://localhost:8080](http://localhost:8080)

## Формула баланса

```
Баланс = Остаток на начало + Доходы − Расходы − Долги − Накопления
```

## Хранение данных

Все данные сохраняются в `localStorage` браузера:

| Ключ | Содержимое |
|------|------------|
| `familyBudgetOperations` | Список операций |
| `familyBudgetBalances` | Остатки на начало месяцев |
| `familyBudgetPlan` | Плановые лимиты расходов |

При первом запуске приложение автоматически переносит данные из старых версий (`familyBudgetOperationsPro`, `familyBudgetBalancesPro`).
